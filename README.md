# 银龄岚途 · 乡村智慧养老综合管理平台

面向乡村 / 海岛养老场景的 PC 端 Web 管理系统，对接「银龄守护」智能应急手环与华为云 IoT 能力，覆盖老人健康监测、应急告警闭环、服务工单调度与数据统计分析全流程。落地场景为福建省平潭综合实验区。

> 华为开发者大赛 · 智慧民生赛道参赛作品
> 参赛单位：福州工商学院 · 银龄岚途团队

## 运行方式

无需构建、无需后端、无需联网，直接双击 `index.html` 即可运行（推荐 Chrome / Edge）。

如需通过本地服务器访问：

```powershell
python -m http.server 8080
# 或
npx http-server -p 8080
```

然后访问 `http://localhost:8080`。

## 页面清单

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `#/overview` | 系统总览 | 三栏数据大屏：健康分布、设备状态、村居覆盖地图、实时告警、体征趋势、工单与志愿数据 |
| `#/elders` | 老人档案 | 多条件筛选、排序、分页、批量操作、新增 / 编辑档案 |
| `#/elders/:id` | 老人档案详情 | 基础信息、30 天体征曲线、服务与告警记录、会员信息 |
| `#/devices` | 智能设备 | 设备概览、华为云 IoT 接入说明、在线状态、电量、绑定关系 |
| `#/devices/:id` | 设备详情 | 设备参数、实时上报日志（5 秒刷新）、远程重启 / 用药提醒 / SOS 配置 |
| `#/alerts` | 应急告警 | 分级告警列表、类型分布、处置弹窗、误报标记、一键拨号 |
| `#/orders` | 服务工单 | 待处理 / 进行中 / 已完成流转、派单、结案、现场照片与家属评价 |
| `#/orders/:id` | 工单详情 | 服务流程时间线、服务小结、评价 |
| `#/reports` | 数据报表 | 覆盖率 / 健康趋势 / 服务效能 / 设备运营，支持周期切换、CSV 导出、民政上报制式报表 |
| `#/ai` | AI 健康分析 | 盘古大模型风险评估、个性化建议、群体洞察、症状问答 |
| `#/settings` | 系统设置 | 个人资料、密码、账号管理、角色权限、告警阈值、服务套餐、村居机构、操作日志 |
| `#/family` | 家属视图 | 老人健康概况、体征档案、告警记录、服务记录、设备状态 |

## 目录结构

```
index.html                  单页入口（登录页 + 后台框架骨架）
vendor/echarts.min.js       ECharts 5.5.1（本地化，离线可用）
assets/css/
  tokens.css                设计令牌、重置、排版工具
  layout.css                登录分屏、侧栏 / 顶栏 / 内容区框架
  components.css            按钮、表单、表格、弹窗、Toast 等通用组件
  pages.css                 大屏、老人档案、设备
  pages-2.css               告警、工单、报表
  pages-3.css               AI、设置、家属视图
assets/js/
  core/icons.js             线性图标库（24×24）
  core/utils.js             格式化、日期、伪随机、下载、动画
  core/store.js             会话、角色权限、业务数据副本
  core/router.js            Hash 路由（支持 /path/:id 与 query）
  core/ui.js                Toast / 模态框 / 抽屉 / 分页 / 提示音
  core/charts.js            ECharts 主题与图表工厂
  data/mock.js              平潭乡村养老模拟数据（固定种子）
  pages/*.js                各页面渲染与交互
  app.js                    应用外壳、导航、权限守卫、实时告警
```

## 设计规范

- 主色：温暖深海蓝 `#165DFF`；辅助色：暖阳橙 `#FF7D00`、健康绿 `#00B42A`、预警红 `#F53F3F`
- 中性色：背景 `#F5F7FA`、正文 `#1D2129`、次级 `#4E5969`
- 正文 14px，标题 16–20px，数字使用 Bahnschrift 等等宽字体并启用 `tabular-nums`
- 圆角统一 8px，控件最小高度 36px，图标为 1.6px 线性风格
- 适配 1920×1080 与 1366×768，支持浏览器缩放；窄屏自动折叠侧栏

## 说明

- 全部数据为演示模拟数据，按固定随机种子生成，刷新后保持一致；时间基于「今天」动态计算。
- 华为云 IoT、盘古大模型、鸿蒙智联为技术底座展示，未接入真实云服务。
- 告警提示音由 WebAudio 实时合成，可在顶栏开关。
- AI 建议内容为模板化生成，仅用于演示，不作为诊疗依据。
