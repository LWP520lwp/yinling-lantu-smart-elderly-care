# 银龄岚途 · 乡村智慧养老综合管理平台

面向乡村 / 海岛养老场景的 PC 端 Web 管理系统，对接「银龄守护」智能应急手环与华为云 IoT 能力，覆盖老人健康监测、应急告警闭环、服务工单调度与数据统计分析全流程。落地场景为福建省平潭综合实验区。

> 华为开发者大赛 · 智慧民生赛道参赛作品
> 参赛单位：福州工商学院 · 银龄岚途团队

## 运行方式

无需构建、无需后端、无需联网，直接双击 `index.html` 即可运行（推荐 Chrome / Edge）。

如需通过本地服务器访问：

```powershell
python -m http.server 8080
# 或
npx http-server -p 8080
```

然后访问 `http://localhost:8080`。

## 数据脱敏与权限

老人档案中的姓名、手机号、住址按角色分级展示。原始数据仍保留在 `assets/js/data/mock.js`，脱敏只发生在渲染层与导出层，不改变数据本身。

| 角色 | 姓名 | 手机号 | 住址 | 档案可见范围 |
| --- | --- | --- | --- | --- |
| 超级管理员 `admin` | 列表页脱敏，详情页显示原文 | 列表页脱敏，详情页显示原文 | 详情页显示原文 | 全量 |
| 社区社工 `shegong01` | 一律脱敏（林水妹 → 林*妹） | 一律脱敏（13912342186 → 139****2186） | 仅到乡镇 / 村居级 | 可见，但展示、导出、编辑回填均为脱敏值 |
| 老人家属 `family01` | 家属视图保留本人老人姓名 | 一律脱敏 | 仅到乡镇 / 村居级 | 仅绑定老人，其余档案提示无权查看 |

脱敏作用于全部老人姓名展示点：老人列表与详情、服务工单、应急告警、数据报表、智能设备、系统总览实时告警、AI 健康分析、页面面包屑与实时告警浮窗。管理员按上表保留原文能力，其他角色统一脱敏。

导出规则：

- 老人档案、告警处置台账、服务工单的 CSV 导出：非管理员输出脱敏值，管理员输出原文。
- 老人档案的「导出完整档案」仅管理员可见，点击后需二次确认，确认后才导出真实姓名与联系电话；取消不产生文件。
- 报表页的村居 / 乡镇统计报表本身不含个人信息，按聚合口径直接导出。

编辑档案：

- 非管理员打开编辑抽屉时，姓名、住址、家属姓名、家属电话均回填脱敏值，并提示「当前为脱敏值，修改请重新输入完整内容」。
- 未修改的字段在保存时自动还原为原始真实值，不会把 `*` 写回数据；修改过的字段按新输入内容保存。

AI 请求：

- 发给大模型的老人档案姓名固定为「该老人」，不携带手机号、身份证号与住址明细，仅保留村居与乡镇作为地域上下文。

## 操作审计

登录与关键业务操作会写入后端审计表 `audit_logs`（`backend/app/iot/storage.py`），管理员可在「系统设置 → 操作日志」查看真实记录，社工与家属无查询权限。

| 动作 `action` | 触发点 | 记录要点 |
| --- | --- | --- |
| `login` / `logout` | 登录页（`login` 由后端 `/api/auth/login` 写入）、右上角退出（前端上报） | 成功 / 失败、账号、来源 IP；失败只记账号，不含口令 |
| `elder_view` | 打开老人档案详情 | 老人档案 ID |
| `elder_export` | 导出老人档案 CSV / 完整档案 | 条数与档案编号，不含档案内容 |
| `report_export` | 数据报表导出 | 报表口径与导出条数 |
| `alert_handle` / `alert_false_alarm` | 告警处置 / 标记误报 | 告警 ID、处置结果与告警级别 |
| `device_command` | 设备远程重启等命令下发 | 设备 ID、命令名与结果（`ok` / `failed` / `disabled`） |

- 登录成功与失败的审计由后端 `POST /api/auth/login` 内部统一写入，前端不重复上报；退出登录、档案查看 / 导出、报表导出、告警处置等业务操作由前端 `YL.api.audit()` 静默上报，上报失败不弹出任何错误，也不影响页面操作；
- 后端不可用（未启动 / 网络不通 / 接口报错）时，「操作日志」页自动回退内置演示数据，并在列表上方标注「当前为演示数据（审计服务未连接）」；请求进行中只显示加载占位，接口成功但无记录时显示「暂无审计记录」空状态、不降级；
- 审计写入失败只影响日志本身：`POST /api/audit` 返回 `200 {"ok":false}`，登录、AI 对话、命令下发等主流程照常完成。

## 设计规范

- 主色：温暖深海蓝 `#165DFF`；辅助色：暖阳橙 `#FF7D00`、健康绿 `#00B42A`、预警红 `#F53F3F`
- 中性色：背景 `#F5F7FA`、正文 `#1D2129`、次级 `#4E5969`
- 正文 14px，标题 16–20px，数字使用 Bahnschrift 等等宽字体并启用 `tabular-nums`
- 圆角统一 8px，控件最小高度 36px，图标为 1.6px 线性风格
- 适配 1920×1080 与 1366×768，支持浏览器缩放；窄屏自动折叠侧栏

## 手工验收清单

前置：在 `backend` 目录启动后端（`uvicorn app.main:app --port 8000`，详见 `backend/README.md`），再双击 `index.html`。逐条勾选：

- [ ] **1. 管理员可查日志**：`admin` 登录后进入「系统设置 → 操作日志」，显示真实记录且**没有**「当前为演示数据」标注；控制台执行 `GET /api/audit/logs` 返回 `{"items":[...]}`（登录本身仅由后端写入 1 条 `login`，前端不重复上报）
- [ ] **2. 非管理员返回 403**：`shegong01` 或 `family01` 登录后调用 `GET /api/audit/logs`，返回 **403** `FORBIDDEN`
- [ ] **3. 档案操作落库**：以 `admin` 进入任一老人详情页、再导出老人档案，日志中出现 `elder_view` 与 `elder_export` 两条记录
- [ ] **4. 后端停机降级**：关闭后端后刷新页面，页面功能仍可用，「操作日志」自动显示内置演示数据
- [ ] **5. 降级标注可见**：第 4 步的场景下，日志列表上方显示「当前为演示数据（审计服务未连接）」
- [ ] **6. 写库失败不影响主流程**：审计写库失败时 `POST /api/audit` 返回 `200 {"ok":false}`，登录、AI 对话、命令下发等操作仍能正常完成

> 第 4～5 条也可用浏览器「离线」模式或改错前端 `API_BASE` 复现；第 1～3、6 条的命令行验证见
> `backend/README.md` 第十七章第 8 节。

- 全部数据为演示模拟数据，按固定随机种子生成，刷新后保持一致；时间基于「今天」动态计算。
